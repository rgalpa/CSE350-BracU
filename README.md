## 🗂️ Repository at a Glance

- **Theory:** lecture slides, lecture notes, formulas, recordings, assignments, practice sheets, quizzes and solved problems.
- **Labs:** lab guide, lab policy, experiment sheets, solutions and project resources.
- **Project:** PWM project planning, explanations, circuit schematic, report and group material.
- **Text Books:** references covering op-amps, microelectronics, digital logic, MOS/CMOS, ADC/DAC, Schmitt triggers and signal generators.
- **Previous Exams:** question papers and available solutions from multiple semesters.
- **Course Policy:** course-level policy document.

## 🎯 Main Topics Covered

Based on the materials currently stored in this repository, the collection covers:

**Digital Logic Families:** Diode Logic, RTL, DTL, TTL, HTL, ECL, MOS and CMOS  
**Analog / Mixed-Signal:** Op-Amp Comparator, Schmitt Trigger, Signal Generator, ADC and DAC  
**Transistor Logic:** MOSFET Logic and CMOS Logic  
**Problem Solving:** noise margin, fan-out, power dissipation, logic circuits, ADC/DAC calculations and Schmitt-trigger/signal-generator problems  
**Assessment Prep:** assignments, quizzes, practice sheets, midterms, finals and solved papers
